# Стоимость «Threads Digest» на Cloudflare

Ключевое решение по бюджету: **тяжёлое (ffmpeg + прокси) крутится локально на ПК
пользователя** (`local/`), а **Cloudflare платит только за лёгкое** — Worker, D1, R2,
Queues, Workers AI. Причина: бюджет контейнеров аккаунта **уже забит другим проектом**,
поэтому любой Cloudflare-контейнер здесь увеличил бы оверхед сверх $5. Локальный ПК
делает ffmpeg бесплатно, вне бюджета аккаунта.

## Где что живёт

| Задача (ТЗ)            | Где живёт                                  | Как |
|------------------------|--------------------------------------------|-----|
| монтаж Shorts (ffmpeg) | **Локально на ПК** (`local/server.js`)      | `VIDEO_RENDERER_URL` (туннель) |
| TTS (Piper)            | там же (офлайн, без API-оплат)             | `POST /tts` |
| прокси сборщика        | **Локально на ПК** (`local/server.js`)      | `PROXY_GATEWAY_URL` → `GET /fetch` |
| всё остальное          | Worker + D1 + R2 + Queues + Workers AI     | — |

Локальный сервис доступен Worker'у через туннель (cloudflared/ngrok), см. `local/README.md`.

## Нагрузка в день (ТЗ §4.8 / §9: 3–5 постов TG, 1–2 Shorts)

- **Сбор (cron каждые 5 мин):** ~400 страниц/день → запросы к локальному `/fetch`.
  Прокси-трафик идёт с IP твоего ПК (бесплатно; резидентный IP — плюс для Threads).
  **$0 на Cloudflare.**
- **Рендер Shorts (1–2/день):** ffmpeg на ПК, ~30–90 с на ролик. **$0 на Cloudflare**
  (платит только электричество/инет твоего ПК).
- **Worker:** ~500–1500 вызовов/день (cron, queue, AI, паблиш) по миллисекундам
  каждый → входит в базу Paid.
- **Workers AI:** 5–10 текстов/день × ~1–2K токенов = ничтожно vs 10K нейронов/день бесплатно.

## Итог по деньгам

| Статья                       | Стоимость         |
|------------------------------|-------------------|
| Workers Paid (база)          | **$5.00/мес** (уже оплачено аккаунтом) |
| ffmpeg + прокси (локально)   | **$0** (твой ПК)  |
| D1 (Paid квоты)              | $0 (в лимитах)    |
| R2 (сторадж + egress)        | $0 (10 GB + egress free) |
| Queues (1M оп/мес)           | $0 (в лимитах)    |
| Workers AI (нейроны)         | $0 (10K/день free) |
| **ДОП. затраты этого проекта**| **≈ $0** (в рамках уже оплаченного $5) |

**Главное:** этот проект почти ничего не добавляет к счёту аккаунта — вся тяжёлая
работа ушла на локальный ПК. $5 Workers Paid, которые ты уже тратишь на другой проект,
покрывают и этот (Worker/D1/R2/Queues/AI здесь мизерны). Никаких Cloudflare-контейнеров.

## Если захочешь перенести рендер в Cloudflare

Только если появится отдельный аккаунт/бюджет. Тогда `local/server.js` можно упаковать
в Cloudflare Container (там он уже готов как Docker-образ) — но в текущем аккаунте это
гарантированно уведёт за $5. Поэтому по умолчанию — локально.
